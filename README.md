# Отображение кулдауна нюха

Userscript для [CatWar](https://catwar.su): пока действие **«Принюхаться»** на откате, оно не
исчезает из меню действий, а показывается серой неактивной иконкой с обратным таймером до момента,
когда снова станет доступно.

Мод **пассивный**: ничего не делает за игрока, не автоматизирует действия, не трогает боевой
режим и не отправляет никаких запросов на сервер — только читает интерфейс и рисует поверх.

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) (или совместимый менеджер
   userscript-ов).
2. Откройте файл установки: **[cooldown.user.js](https://raw.githubusercontent.com/kramvenseles/catwar-smell-cooldown/main/cooldown.user.js)** — Tampermonkey предложит установить скрипт.
3. Откройте Игровую `https://catwar.su/cw3/`. В консоли появится строка
   `[cwmod-cd] версия ... загружена`.

## Как это работает

- Отсчёт мод вычисляет по открытой формуле навыка «Нюх» из [справки игры](https://catwar.su/about?id=20)
  (`3600/(УН−2)`, до 4 уровня — фиксированный час); уровень берётся из блока характеристик.
- Иконка убирается по факту **реального** возврата действия в меню, а не по таймеру.
- Состояние хранится локально в браузере (`localStorage`) и переживает перезагрузку.

## Статус

Проверочный прототип. На catwar.su моды регулируются: до распространения требуется согласование
с «Почтовиком» (см. [политику модов](https://catwar.su/about?id=75)).
